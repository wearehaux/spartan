title: Icon Button

`sp-icon-button` is a square button that shows only an icon. An icon has no text, so `label` is required to give the control an accessible name. It shares its behavior with [Button](/docs/components/button): a native `<button>` in the shadow root, form association, and the same states.

Design reference: [Icon Button set in Spartan DS](https://www.figma.com/design/PhcMPmdpkpgxH3N83SvpBY/Spartan-DS?node-id=326-63).

## Usage

```ts
import '@spartan/components/icon-button';
import '@spartan/components/tokens.css';
```

```html
<sp-icon-button label="Add item">
  <svg aria-hidden="true" viewBox="0 0 24 24"><path d="M12 5v14M5 12h14" stroke="currentColor" stroke-width="1.5" fill="none" /></svg>
</sp-icon-button>
```

## Sizes

`xs` is Extra small (24px), `sm` is Small (32px), and `base` is Base (40px) in Relaxed density.

Compact keeps Extra small at 24px, changes Small to 28px and Base to 32px. Glyphs are 16px for Extra small/Small, and 20px/18px for Base in Relaxed/Compact. The frame stays square and centered when the glyph is replaced. Arrange toolbars with wrapping or scrolling when the controls cannot fit; do not squeeze targets below their chosen size.

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `label` | `label` | `string` | `''` | Accessible name. Required. |
| `variant` | `variant` | `'primary' \| 'secondary' \| 'danger' \| 'ghost' \| 'dashed'` | `'primary'` | Visual emphasis. `danger-subtle` and `warning` are not available. |
| `size` | `size` | `'xs' \| 'sm' \| 'base'` | `'base'` | Control size. Density modes scale each. |
| `type` | `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | Native button behavior inside a form. |
| `disabled` | `disabled` | `boolean` | `false` | Prevents interaction and removes the control from the tab order. |
| `name`, `value` | `name`, `value` | `string` | `''` | Submitted with the form when this control submits it. |

## Slots and parts

| Name | Content |
| --- | --- |
| default slot | The icon, usually an inline `<svg>` marked `aria-hidden`. |
| `button` part | The native button element. |

## States

Default, hover, pressed, focus and disabled use the shared [Button](/docs/components/button) Style recipe. The component has no loading or selected/toggle property; a persistent on/off control belongs to its own component. Disabled actions leave the tab order and suppress pointer, keyboard and form activation. `updateComplete` includes form-associated disabled updates, so code can safely focus immediately after re-enabling.

## Theme contract

Style owns the radius (Atlas 8px, Selene 12px, Helios pill, Ares square), neutral treatment and state recipes. Actions have no shadow. Brand owns Primary fills; System owns the keyboard focus indicator independently. Density supplies the size and glyph metrics. Icon Button has no local field Appearance or Shape property; `variant` selects action emphasis.

Component aliases reuse shared roles rather than duplicating values:

| Alias | Source |
| --- | --- |
| `--sp-icon-button-size-{xs,sm,base}` | Button height aliases to Density tiers. |
| `--sp-icon-button-icon-size-{xs,sm,base}` | Button glyph aliases to Density; Extra small reuses Small. |
| `--sp-icon-button-focus-{color,radius,width,offset}` | Shared Button focus roles: System color, Style radius, 2px stroke and 4px offset. |

Local alias overrides apply to Icon Button only. Keep its square target, visible focus and contrast when adapting a product. In forced-colors mode focus uses the user's Highlight color.

## Direction and composition

Native `dir` inherits through the shadow root and supports nested overrides. The icon stays centered in both directions. The component does not mirror artwork; the consumer owns direction-sensitive glyph selection. Default slot content is decorative, hidden from the accessibility tree and must not contain interactive elements. The required `label` owns the action name independently of icon swaps.

## Forms

```html
<form>
  <input name="title" aria-label="Title" required />
  <sp-icon-button label="Save" type="submit" name="intent" value="save">
    <!-- Decorative save glyph -->
  </sp-icon-button>
</form>
```

`type="submit"` respects native form validation and includes the control's name/value. `type="reset"` restores the form's fields. The read-only `form` getter returns the associated form or `null`.

## Accessibility

- `label` is trimmed and becomes `aria-label` on the native button. A missing or whitespace-only label, including one that becomes blank after an update, logs a warning and leaves no empty `aria-label`. Supply an action name; the glyph cannot provide it.
- Keyboard behavior is that of a native button: Tab to focus, Enter or Space to activate.
- Use a label that describes the action, such as "Add item", not the icon, such as "Plus".
- Extra small's 24px target meets the minimum geometry used here; prefer a larger density/size when touch use needs it. Keep spacing between controls.
