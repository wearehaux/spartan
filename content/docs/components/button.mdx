title: Button
description: An action button with seven variants, two sizes, four styles, and form support.
---

`sp-button` renders a native `<button>` in its shadow root, so Tab, Enter, and Space behave as for any button. It is form-associated: `type="submit"` and `type="reset"` act on the closest form.

<StorybookEmbed story="components-button--playground" title="Button playground" height={200} />

Design reference: [Button set in Spartan DS](https://www.figma.com/design/PhcMPmdpkpgxH3N83SvpBY/Spartan-DS?node-id=21-27). Sizes map to the Figma set: `sm` is Small and `base` is Base. The corner radius, Secondary treatment, and state colors come from the active style, so there is no `shape` property.

## Usage

```ts
import '@spartan/components/tokens.css';
import '@spartan/components/button';
```

```html
<sp-button>Save</sp-button>
<sp-button variant="secondary" size="sm">Cancel</sp-button>
<sp-button variant="danger" loading>Deleting</sp-button>
```

## Styles

The style setting (`data-sp-mode-style`: Atlas, Selene, Helios, Ares) owns the corner radius, the Secondary treatment, and every state color. Helios is the pill and Ares is square. A nested attribute re-resolves the style for its subtree.

```html
<div data-sp-mode-style="Helios">
  <sp-button>Pill</sp-button>
</div>
```

## Properties

| Property | Attribute | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `variant` | `variant` | `'primary' \| 'secondary' \| 'danger' \| 'ghost' \| 'dashed' \| 'danger-subtle' \| 'warning'` | `'primary'` | Visual emphasis. |
| `size` | `size` | `'sm' \| 'base'` | `'base'` | Height, padding, and type size. Density modes scale each. |
| `type` | `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | Native button behavior inside a form. |
| `disabled` | `disabled` | `boolean` | `false` | Prevents interaction and removes the control from the tab order. |
| `loading` | `loading` | `boolean` | `false` | Shows a spinner, hides the content, and ignores activation. The button stays focusable. |
| `name` | `name` | `string` | `''` | Submitted with the form when this control submits it. |
| `value` | `value` | `string` | `''` | Submitted with the form when this control submits it. |

The read-only `form` getter returns the associated `HTMLFormElement`, or `null`.

## Slots

| Slot | Content |
| --- | --- |
| default | Button label. |
| `start` | Icon before the label (Figma "Left icon"). |
| `end` | Icon after the label (Figma "Right icon"). |

An icon slot takes up no space until something is slotted. Any inline `<svg>` or `<img>` fits the icon frame.

```html
<sp-button>
  <svg slot="start" aria-hidden="true" viewBox="0 0 24 24"><path d="M12 5v14M5 12h14" stroke="currentColor" stroke-width="1.5" fill="none" /></svg>
  Add
</sp-button>
```

## States

The six Figma states map to behavior, not to properties.

| Figma state | Implementation |
| --- | --- |
| Default | No state applied. |
| Hover | `:hover`, on devices that support hover. |
| Pressed | `:active`. |
| Focus | `:focus-visible`: a 2px ring drawn 4px outside the border edge through `--sp-button-focus-*` aliases. System owns its color, Style owns its radius. In forced colors it uses the system Highlight color. |
| Disabled | `disabled`, or an ancestor `<fieldset disabled>`. |
| Loading | `loading`. |

## Direction

Layout follows the inherited `dir` attribute. `start` is the leading side in both LTR and RTL, and a nested `dir` overrides the document's. Slotted icons are not mirrored, so flip a direction-sensitive icon yourself.

## Density

Heights are 40px (Base) and 32px (Small) in Relaxed, and 32px and 28px in Compact. Wrap content in `data-sp-mode-density="Compact"` to switch. See [Density](/docs/foundations/density).

Button consumes `--sp-button-font-size-{sm,base}`, `--sp-button-line-height-{sm,base}`, and `--sp-button-icon-size-{sm,base}` aliases to the Density roles. Base labels are 15px/22px in Relaxed and 14px/20px in Compact; Small is 14px/20px and 13px/18px. The approved Figma Base sample currently resolves 16px/24px despite its density bindings. The adopted code contract preserves the density values; this intentional difference does not authorize editing the protected Figma page.

## Theme contract

Primary actions use the selected product Brand. Focus uses the independent System role, so changing Purple to Orange does not recolor the keyboard indicator. Style owns radius, neutral treatment and state recipes. Button has no local field Appearance property; its `variant` selects action emphasis. See [Theme ownership](/docs/theming/contract).

<StorybookEmbed story="components-button--theme-contract" title="Nested Button theme contract" height={360} />

The focus geometry aliases are `--sp-button-focus-width` (2px), `--sp-button-focus-offset` (4px), and `--sp-button-focus-radius` (Style's field focus radius). `--sp-button-focus-color` aliases semantic System focus. Local token overrides are available for product integrations; keep a visible indicator and verify the affected sizes and contrast.

The loading wave retains the approved 16px frame across sizes and densities. Its bar geometry and timing remain local to Button until a reusable Loading component is delivered. Loading preserves the label and layout, sets `aria-busy` and `aria-disabled`, remains focusable and blocks pointer, keyboard and form activation. The wave stops under reduced motion.

## Accessibility

- The shadow root contains a native `<button>`. Focus is delegated to it, so Tab focuses the control and Enter or Space activates it.
- The focus ring uses `:focus-visible`, so it shows for keyboard focus and not for most pointer clicks.
- A `disabled` button is removed from the tab order and does not fire `click`.
- A `loading` button sets `aria-busy="true"` and `aria-disabled="true"`, stays focusable, and swallows activation. The spinner is `aria-hidden`.
- The accessible name is the slotted label. Mark slotted icon SVGs `aria-hidden="true"` so they are not read twice.
- Color pairs come from semantic tokens, so `data-sp-mode-contrast="High"` applies without extra work. Contrast ratios were not measured for this page.
